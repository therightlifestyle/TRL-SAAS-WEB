## 🎯 About TRL

TRL is an early-stage technology company building the **AI-powered operating system for ambitious people**.

We help individuals and businesses:

- **Learn** faster with applied knowledge and skills
- **Build** projects, businesses, and ideas with better systems
- **Automate** repetitive work using AI tools
- **Grow** through community and smart connections

### Our Mission

> Bridge the gap between ambition and execution.

Most people have dreams. Few have systems. TRL exists to give everyone access to the technology, knowledge, and tools needed to build a better future.

- **HTML5** — Semantic markup

## 🚀 Development

### Running Locally

```bash
# Clone the repository
git clone https://github.com/therightlifestyle/The-Right-Lifetsyle.git

# Open index.html in browser
# No build step required
```

### Making Changes

1. Edit `index.html`, `style.css`, or `script.js`
2. Test locally in browser
3. Commit changes
4. Push to main branch
5. Changes go live automatically via GitHub Pages
